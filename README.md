# Currículo Web - Matheus Henrique da Silva

Projeto desenvolvido para a disciplina de Webapps, com o objetivo de criar uma página web estática e interativa utilizando HTML, CSS e JavaScript.

## Sobre o projeto

A página funciona como um currículo/portfólio pessoal, apresentando informações sobre minha formação, experiência profissional, cursos e conhecimentos na área de Tecnologia da Informação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
